#  Weekly Study Time Tracker

## Short Description
This is a simple command-line Python utility designed to help users track and estimate their study time. It takes the number of hours studied in a single day as input and projects the total hours of study for the entire week, assuming a consistent daily input. This helps users quickly gauge their potential weekly progress toward their educational goals.

## How to Run
1. Ensure you have Python installed on your system (Python 3 is recommended).
2. Clone or download this repository.
3. Navigate to the project directory (`python_github_assignment`) in your terminal or command prompt.
4. Execute the program using the command:

```bash
python app.py
